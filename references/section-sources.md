# 截面来源与软件输出文件

## 先确定来源

截面可由用户直接指定，也可从用户指定的软件导出文件读取。记录适用构件、标高
范围、版本和单位。直接指定应包括截面类型、实际尺寸、材料；尺寸不全时只补问
缺少的字段。指定截面不能被之后的导入覆盖，冲突列出原值及导入值。

读取软件文件是取得截面指派与数值定义，不改变CAD几何的来源。先核实构件ID、
坐标系、长度单位、分段和版本，不能因为模型坐标不同就覆盖已核查的CAD坐标。

## 用户直接指定

将指定值写入对应梁、柱或杆件行，并在来源记录中标注“用户指定”、适用范围及
原始说明。没有软件来源时，不需要运行S2K工具。核心筒柱按实际截面变化区段
记录上下标高；一根梁变化截面时在同一行备注中写距起点的范围。

## 通用软件导出文件

先检查实际内容，再决定适配方法。文本、CSV、Excel、XML只是容器，不意味着
字段约定相同。至少提取并关联：

- 构件标识、节点坐标或可信的CAD构件映射。
- 构件的实际分析截面指派，区别自动选型组、设计结果和未指派值。
- 截面数值定义及单位、材料覆盖；组合截面的各组成材料、位置和旋转。
- 原文件哈希、工作表/表名、行号及原构件号。

按端点和完整轴线覆盖匹配，不采用最近杆件推定身份。同一根CAD梁在模型中
可能有多个子段；检查覆盖是否完整、是否重叠、截面是否变化。可接受误差应
根据源精度说明，不能扩大容差来掩盖布置变化。无法唯一对应时保留待核。

当前没有通用的其他软件解析器。新增适配时验证实际导出格式，先在少量构件上
对照，再扩展；不能把未解析的二进制文件当作已经支持。

## 附带的S2K工具

`read_s2k_sections.py`读取：

- `PROGRAM CONTROL`中的单位。
- `JOINT COORDINATES`中的整体坐标。
- `CONNECTIVITY - FRAME`中的直线框架连接。
- `FRAME SECTION ASSIGNMENTS`中的`AnalSect`和材料覆盖。
- `FRAME SECTION PROPERTIES 01 - GENERAL`中的真实数值。

处理引号和续行，忽略I/J方向，检查同轴模型段覆盖。输入工作簿来自
`parameters.py create`，应包含一个`trace`来源表。使用新输出文件名。
模型未对应或冲突的构件不填猜测值；已有不同截面值时停止导入，保留人工值。

```text
python scripts/read_s2k_sections.py input.xlsx model.s2k --output sections.xlsx --report sections.json --tolerance-mm 0.01
```

真实尺寸直接显示在截面栏，原名称留在备注和`截面定义_S2K`的原名列。
数值与名称不符时以指定软件的数值定义作为导入值，并提示差异，不修正源模型。
尺寸mm、面积mm²、惯性矩mm⁴；截面惯性矩不等于构件刚度修正系数。

现有尺寸显示支持对称/非对称工字形和箱形，不包含圆管、槽钢、角钢、任意多边形、
变截面或自动选型截面的完整解析。曲线框架不参与此轴线匹配，可能导致未覆盖。
遇到这些情况需另外适配和核实，不按截面名换成相似工字形。

已导入的名称要改为尺寸显示，可加`--format-existing`，指定新输出和报告。
该模式只接受原名仍可在同一哈希S2K中解析的记录，不重新匹配几何。

## 核心筒柱与组合截面

先完成梁截面导入，再运行：

```text
python scripts/read_core_columns.py sections.xlsx model.s2k --output columns.xlsx --report columns.json
```

从旧`core_column`定位记录出发，按同XY竖向框架链匹配，核对间隙、重叠和柱顶，
将相邻同截面段合并为`core_column_section`。原定位记录保存在来源记录中。
这一转换不再接受已转换的区段表作为旧定位输入。

组合截面读取`SECTION DESIGNER PROPERTIES 01`、`09 - SHAPE BOX/TUBE`和
`12 - SHAPE SOLID RECTANGLE`。当前工具限于单根箱形钢管和未旋转的混凝土矩形，
核对所有组成形状数量、填芯尺寸、位置、材料和包络。其他形状或复杂组合需
单独解释。保留原始组成字段，不把软件的基准材料等效面积当作物理总面积。

## 输出和人工修改

`截面定义_S2K`是补充定义表，不是新增构件。其他软件接收参数时，应解析行内
真实尺寸和必要的分段/组合定义；不能拿原软件名称去查另一个软件的同名库截面。
软件导入结果仍待人工核查。核查后的工作簿是下一轮修改的入口。
